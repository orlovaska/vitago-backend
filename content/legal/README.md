# Пользовательское соглашение и политика конфиденциальности

Здесь лежат исходные тексты документов. Приложение ссылается на них с экрана
профиля и с экрана согласия, а согласие пользователя привязывается к версии
документа — поэтому документ считается опубликованным только тогда, когда у
него есть версия с загруженным PDF.

## Что здесь есть

| Файл | Документ |
| --- | --- |
| [terms.md](terms.md) | Пользовательское соглашение |
| [privacy.md](privacy.md) | Политика конфиденциальности |

Оба текста — **черновики**. Они написаны по тому, что приложение действительно
делает (геопозиция, аудио, офлайн-кэш, оплата, пуши, удаление аккаунта), и их
нужно вычитать юристу до публикации: подставить реквизиты правообладателя,
проверить формулировки об оплате и о персональных данных.

Места, которые нельзя опубликовать как есть, отмечены как `<<...>>`.

## Как опубликовать

1. Вычитать текст и заменить все `<<...>>` на настоящие данные.
2. Сделать из каждого `.md` PDF — бэкенд принимает версию документа только в
   виде PDF (`application/pdf`), так документ остаётся читаемым без интернета
   и не меняется задним числом.
3. Положить PDF рядом, например `content/spb/legal/terms.pdf`.
4. Добавить в `content/<город>/manifest.json` раздел `legal`:

   ```json
   "legal": [
     {
       "type": "terms",
       "file": "legal/terms.pdf",
       "publicUrl": "https://vitagoguides.ru/legal/terms",
       "requiresReconsent": true
     },
     {
       "type": "privacy",
       "file": "legal/privacy.pdf",
       "publicUrl": "https://vitagoguides.ru/legal/privacy",
       "requiresReconsent": true
     }
   ]
   ```

   `publicUrl` — веб-страница с тем же текстом: приложение открывает её, когда
   она есть, и сам PDF, когда её нет. `requiresReconsent: true` означает, что
   изменение существенное и у всех спросят согласие заново; правки опечаток
   публикуются с `false`.

5. Импортировать: `npm run content:import -- content/spb/manifest.json`.

Повторный импорт того же текста добавляет новую версию, а не переписывает
старую: то, с чем люди уже согласились, остаётся в истории.
