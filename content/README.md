# Бриф: что сдаёт автор маршрута

Документ для человека, который собирает контент маршрута (экскурсии) для приложения Vitago.

Сдача — это папка города: файл `manifest.json` со всем текстом и структурой плюс папки с медиа.
Манифест загружают в базу командой импорта, поэтому названия полей менять нельзя.

> **Манифест — источник правды.** Контент не правят руками в базе: правят манифест и запускают
> импорт заново. Повторный импорт безопасен — он приводит базу к тому, что написано в файле
> (маршрут ищется по `slug`, его точки заменяются целиком). Поэтому манифест обязан всегда
> отражать актуальную версию маршрута.

---

## Как устроена сдача

Все материалы города лежат в одной папке, рядом с этим файлом. Готовый пример — папка [spb](spb/):

```
content/<город>/
  manifest.json        ← весь текст и вся структура
  audio/               ← mp3: озвучка точек и вступление маршрута
  photos/              ← фотографии точек, обложка и карусель маршрута
  markers/             ← иконки точек на карте (обычный и «закрытый» вид)
```

В манифесте медиа указывается **относительным путём от самого манифеста**: `photos/ermitazh.jpg`,
`audio/point-ermitazh.mp3`. Никаких идентификаторов, номеров и ссылок — только путь к файлу.
Импорт сам загрузит файлы; одинаковые файлы загружаются один раз, так что переиспользовать одно
фото в нескольких местах можно спокойно.

**Что заполняет не автор маршрута:**

- блоки `app` (настройки приложения города) и `legal` (соглашение и политика) — их заводит команда один раз на город;
- цену маршрута `priceKopecks` — ставьте `0`, менеджер проставит итоговую перед импортом;
- длительность и протяжённость маршрута — считаются по маршруту, руками их писать не нужно;
- часы работы точек — их подтянут из внешнего источника;
- категории точек — пока не заполняем;
- субтитры к аудио — их расставляет отдельный инструмент.

Весь текст пока делается **только на русском**.

## Маршрут

Маршрут — один элемент массива `tours` в манифесте.

```json
{
  "slug": "nevskii-prospekt",
  "status": "published",
  "priceKopecks": 0,
  "position": 1,
  "mapViewport": {
    "center": { "latitude": 59.93365, "longitude": 30.33535 },
    "zoom": 14.8,
    "bounds": {
      "north": 59.9395,
      "west": 30.300575,
      "south": 59.9278,
      "east": 30.370125
    }
  },
  "cover": "photos/kazanskiy-sobor.jpg",
  "images": [
    "photos/kazanskiy-sobor.jpg",
    "photos/dom-zingera.jpg",
    "photos/anichkov-most.jpg"
  ],
  "translations": [
    {
      "locale": "ru",
      "title": "Невский проспект",
      "subtitle": "8 точек · центр",
      "summary": "Прогулка по главной улице города от Адмиралтейства до площади Восстания.",
      "description": "Невский проспект за один проход: соборы, торговые дворы, театры и доходные дома.\n\nМаршрут идёт строго по прямой и заканчивается у Московского вокзала.",
      "introAudio": "audio/route-nevsky.mp3"
    }
  ],
  "points": []
}
```

Что писать в полях:

| Поле | Что это |
|---|---|
| `slug` | Адрес ссылки: латиницей, строчными, через дефис. Только буквы, цифры и дефис, 2–64 знака |
| `status` | `"published"` — маршрут виден в приложении, `"draft"` — не виден. Пока маршрут не вычитан, ставьте `"draft"` |
| `position` | Место маршрута в списке приложения, начиная с 0 |
| `title` | Название маршрута, как на обложке. До 100 знаков |
| `subtitle` | Одна строка под названием на экране маршрута. До 300 знаков |
| `summary` | 1–2 предложения для карточки в списке маршрутов. До 1000 знаков |
| `description` | Полное описание на экране маршрута. **Максимум 2 абзаца**, абзацы разделяются `\n\n` |
| `introAudio` | Вступительное аудио маршрута, если есть |
| `cover` | Вертикальная обложка маршрута |
| `images` | Карусель на экране маршрута; порядок отображения равен порядку в массиве |

`summary` и `description` — разные поля: короткое для карточки в списке, полное для экрана
маршрута. Заполняются оба, одинаковым текстом их дублировать нельзя.

**Карта.** `mapViewport.center` — точка, на которой открывается карта: центр между крайними точками
маршрута. `zoom` — от 0 до 22, для пешего маршрута обычно 13–15. `mapViewport.bounds` —
прямоугольник, в который помещается весь маршрут (по нему скачивается офлайн-карта): берите крайние
координаты точек и добавляйте небольшой запас.

## Точки

Точки — массив `points` внутри маршрута, **в порядке прохождения**. Отдельного поля порядка нет:
порядок в массиве и есть порядок точек в приложении.

```json
{
  "latitude": 59.9375,
  "longitude": 30.3086,
  "isFree": true,
  "image": "photos/admiralteystvo.jpg",
  "images": [],
  "marker": "markers/admiralteystvo.png",
  "lockedMarker": "markers/admiralteystvo-locked.png",
  "translations": [
    {
      "locale": "ru",
      "name": "Адмиралтейство",
      "description": "Адмиралтейство начиналось как верфь, заложенная Петром Первым...",
      "address": "Адмиралтейский проезд, 1"
    }
  ],
  "audio": {
    "autoplayRadiusMeters": 40,
    "translations": [
      {
        "locale": "ru",
        "file": "audio/point-admiralteystvo.mp3",
        "transcript": "Адмиралтейство начиналось как верфь, заложенная Петром Первым..."
      }
    ]
  }
}
```

Что писать в полях:

| Поле | Что это |
|---|---|
| `latitude`, `longitude` | Координаты с карты, точка как разделитель: `59.9375`, `30.3086`. 4–6 знаков после точки |
| `name` | Название места. До 100 знаков |
| `description` | Текст на карточке точки, 1–3 абзаца |
| `address` | Улица и дом; если адреса нет (сквер, набережная) — ориентир. До 500 знаков |
| `isFree` | `true` только у демо-точек, доступных без покупки маршрута (обычно 1–2 первые) |
| `image` | Главное фото точки |
| `images` | Дополнительные фото карусели на карточке точки; можно оставить пустым массивом |
| `marker`, `lockedMarker` | Иконки на карте: обычная и серая для ещё не купленного маршрута |
| `audio.file` | Озвучка точки |
| `audio.transcript` | Текст озвучки **слово в слово** |
| `audio.autoplayRadiusMeters` | На каком расстоянии аудио включится само. По умолчанию 40, допустимо 5–1000. Больше — для площадей и набережных, меньше — для тесной застройки |

`transcript` обязан совпадать с озвучкой слово в слово: по нему машина расставляет тайминги. Любое
расхождение — пропущенное слово, «переписал покрасивее», другой порядок фраз — ломает результат.

Если у точки нет озвучки, блок `audio` не указывайте целиком.

## Медиа

Складывайте файлы в папки `audio/`, `photos/`, `markers/` внутри папки города. Соглашение об
именовании — как в существующем контенте:

- фото точки — `photos/<латинское-имя-точки>.jpg`, например `photos/admiralteystvo.jpg`;
- иконка точки на карте — `markers/<имя>.png`, «закрытая» серая версия — `markers/<имя>-locked.png`;
- аудио точки — `audio/point-<имя>.mp3`, например `audio/point-admiralteystvo.mp3`;
- вступительное аудио маршрута — `audio/route-<slug маршрута>.mp3`;
- обложка маршрута — вертикальная, `photos/<имя>.jpg`;
- фотографии карусели маршрута — обычные `photos/<имя>.jpg`, порядок задаётся в манифесте.

Допустимые форматы: изображения — **JPG, PNG, WEBP**; аудио — **MP3, M4A**. Файл с другим
расширением импорт не примет.

Имена файлов — латиницей, строчными, через дефис, без пробелов.

## Правила записи и ограничения

- кодировка UTF-8, кавычки только прямые;
- поля, которых нет, просто не указывайте — не пишите пустые строки;
- медиа задаётся относительным путём от манифеста: `photos/…`, `audio/…`, `markers/…`;
- названия полей менять нельзя, регистр важен (`lockedMarker`, а не `LockedMarker`);
- координаты и числа — без кавычек: `59.9375`, а не `"59.9375"`;
- в `translations` всегда одна запись с `"locale": "ru"`.

Импорт проверяет данные и падает с ошибкой, если что-то выходит за рамки:

| Поле | Ограничение |
|---|---|
| `slug` маршрута | строчные латинские буквы, цифры, дефис; 2–64 знака |
| `title` маршрута, `name` точки | до 100 знаков |
| `subtitle` | до 300 знаков |
| `summary` | до 1000 знаков |
| `description` маршрута | максимум 2 абзаца |
| `description` точки | до 20 000 знаков |
| `address` | до 500 знаков |
| `transcript` | до 50 000 знаков |
| `images` маршрута | до 50 фотографий |
| `images` точки | до 20 фотографий |
| `latitude` / `longitude` | −90…90 и −180…180 |
| `zoom` | 0…22 |
| `autoplayRadiusMeters` | 5…1000, целое |

## Чек-лист перед сдачей

- [ ] Точки в массиве `points` идут в порядке прохождения маршрута.
- [ ] У каждой точки проверены координаты: вставили пару в карту — попали в нужное здание.
- [ ] `transcript` каждой точки совпадает с озвучкой слово в слово.
- [ ] `summary` и `description` — разные тексты, полное описание не длиннее двух абзацев.
- [ ] Все пути к файлам ведут к существующим файлам, расширения — из списка допустимых.
- [ ] Имена файлов латиницей, строчными, без пробелов.
- [ ] `manifest.json` открывается без ошибок в любом онлайн-валидаторе JSON.
- [ ] `status` выставлен осознанно: `draft`, пока маршрут не вычитан.
- [ ] `priceKopecks` равен `0` — цену проставит менеджер.

## Частые ошибки

| Ошибка | Как правильно |
|---|---|
| Координаты записаны через запятую как десятичный разделитель (`59,9375`) | Только точка: `59.9375` |
| Координаты в кавычках | Числом, без кавычек |
| Широта и долгота перепутаны местами | В России широта ~40–80, долгота ~20–180 |
| Точки идут в манифесте не в порядке прохождения | Порядок в массиве = порядок в приложении |
| `summary` и `description` заполнены одинаковым текстом | Короткое для карточки, полное для экрана маршрута |
| Полное описание на пять абзацев | Максимум два |
| Транскрипт пересказывает аудио своими словами | Слово в слово |
| Путь к медиа указан от корня диска или репозитория | Относительно манифеста: `photos/…`, `audio/…` |
| Файлы в HEIC, WAV, TIFF | Изображения — JPG, PNG, WEBP; аудио — MP3, M4A |
| Кириллица и пробелы в именах файлов | Латиница, строчные, дефис |
